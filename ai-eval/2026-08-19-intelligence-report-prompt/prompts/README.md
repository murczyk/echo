# Prompt candidates

Candidate files are immutable once evaluated. Runtime uses
`../prompt.txt`, which is byte-for-byte equivalent to candidate 06. Candidate
04 is retained only to explain the rejected detailed-GOI direction; GOI data
is never used by the runtime.

1. `01-source-only.txt`: current source only, neutral compression.
2. `02-recent-examples.txt`: recent pairs added as style-only examples.
3. `03-lexical-ranking.txt`: radio-intercept lexical distinctions added.
4. `04-detailed-goi-rejected.txt`: detailed external analytical framing;
   rejected for latency and example-fact transfer.
5. `05-selected-safe-shared.txt`: selected shared CBR/Pivnich prompt.
6. `06-operator-priority-variants.txt`: operator-first examples and one to
   three ranked variants, added after live operator feedback.
