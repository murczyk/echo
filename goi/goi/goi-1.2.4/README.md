# Інструкція з запуску та роботи з GOIapp

На windows компʼютерах достатньо просто запустити скрипт запуску **start.cmd** який знаходиться в корені директорії з **GOIapp**.

Якщо при першому запуску, на етапі встановлення залежностей, сталася помилка, рекомендується видалити папку _node-modules_ та виконати скрипт **start.cmd** ще раз (від імені адміністратора). Якщо помилка повторилася, перевірте налаштування антивірусу та брандмауеру компʼютера. Якщо вам все одно не вдається запуститися за допомогою **start.cmd** скрипта, спробуйте виконати інструкцію з ручного запуску нижче.

Щоб зупинити **GOIapp** достатньо закрити вікно терміналу яке відкрилося після запуску **start.cmd** (або ручного запуску за допомогою команди _npm run start_).

# Інструкція з ручного запуску GOIapp

Для користувачів Windows, macOS, Linux Node.js можна завантажити тут https://nodejs.org/en/download

## Крок 0 (Разово): Встановлення Node.js

Для запуску **GOIapp** вручну потрібно переконатися що у вас на компʼютері встановлено Node.js.

```bash
node -v
```

```bash
npm -v
```

Команди вище мають повертати номери версії. Мінімальна версія Node.js необхідна для запуску 20.9.0, рекомендується використовувати останню стабільну версію (v24.2.0 на поточний момент)

Будучи в директорії з **GOIapp** проектом (на рівні з файлом _package.json_, наприклад _C:/GOIapp_) виконуємо наступні кроки:

## Крок 1 (Разово): Встановлюємо залежності

Виконується _один раз_ під час встановлення, далі лише _після оновлення_

```bash
npm install
```

## Крок 2: Запускаємо GOIapp

Запускаємо веб сервер **GOIapp**

```bash
npm run start
```

Сервер запуститься за замовчуванням на 4000 порті (http://localhost:4000). Якщо це конфліктує з іншим ПЗ або ви бажаєте змінити порт ви можете вказати порт як опціональний параметр при запуску

```bash
npm run start -- -p 4200
```

## Зверніть увагу

Команда _npm run start_ переводять Термінал (cmd) у режим очікування (_stdin blocking_). Для виходу з цього режиму потрібно натиснути комбінацію клавіш _Ctrl+C_, після чого рядок вводу команд має стати знову доступним.
