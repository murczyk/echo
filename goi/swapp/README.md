# Інструкція з запуску та роботи з SWapp

На windows компʼютерах достатньо просто запустити скрипт запуску **start.cmd** який знаходиться в корені директорії з **SWapp**.

Якщо при першому запуску, на етапі встановлення залежностей, сталася помилка, рекомендується видалити папку _node-modules_ та виконати скрипт **start.cmd** ще раз (від імені адміністратора). Якщо помилка повторилася, перевірте налаштування антивірусу та брандмауеру компʼютера. Якщо вам все одно не вдається запуститися за допомогою **start.cmd** скрипта, спробуйте виконати інструкцію з ручного запуску нижче.

Щоб зупинити **SWapp** сервер достатньо закрити вікно терміналу яке відкрилося після запуску **start.cmd** (або ручного запуску).

Для **Signal** інтеграції потрібно встановити на компʼютер Docker Desktop (https://docs.docker.com/desktop/setup/install/windows-install) та запустити його. Після цього потрібно запустити **signal-start.cmd** скрипт, який розгорне **signal-cli-rest-api** контейнер в вашому локальному Docker середовищі (альтернатива запуску команди **npm run signal:start**).

Якщо у вас виникли проблеми з інтеграціями можливо ці скрипти допоможуть їх вирішити:

**signal-delete.cmd** - видаляє контейнер з Docker, після чого потрібно буде заново запустити **signal-start.cmd** (альтернатива запуску команди **npm run signal:delete**)

**whatsapp-delete.cmd** - видаляє поточну сесію WhatsApp користувача та кеш файли, після чого потрібно буде перезапустити **SWapp** та зісканувати QR-код (альтернатива запуску команди **npm run whatsapp:delete**)

# Інструкція з ручного запуску SWapp

Файл _How-to-start.pdf_ мітить додаткову інформацію та посилання на завантаження Node.js та Docker.

## Крок 0 (Разово): Встановлення Node.js

Для запуску **SWapp** вручну потрібно переконатися що у вас на компʼютері встановлено Node.js.

```bash
node -v
```

```bash
npm -v
```

Команди вище мають повертати номери версії.

Будучи в директорії з **SWapp** проектом (на рівні з файлом _package.json_, наприклад _C:/SWapp_) виконуємо наступні команди:

## Крок 1 (Разово): Встановлюємо залежності

Виконується _один раз_ під час встановлення, далі лише _після оновлення_

```bash
npm install
```

## Крок 2: Запускаємо SWapp

Запускаємо клієнт та сервер **SWapp** (якщо такий передбачено у конфігурації)

```bash
npm start
```
