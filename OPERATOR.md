# Інтеграція із ЕХО Оператор - базовий сценарій

1. додати новий логін в ЕХО, із типом API (наприклад api-lyman)
2. В ЕХО Оператор конфіг додати АПІ юзера який ходить в ехо
3. відправити перехоплення в Signal/Whatsapp групу, зайти в ЕХО і перевірити що з'явилась нова дзеркальна (орфан) група (по дефолту, можна вимкнути в `feature_auto_generate_operator_groups`)
4. встановити їй напрямок та переконатись що перехоплення надійшло
5. піти в джерело ЕХО Оператора з якого треба скидати розпізнані аудіо в ЕХО. Виставити в налаштуваннях Джерела на вкладці Інше групу в яку летить розпізнаний текст, поставити галочку Відправляти Необроблений Розпізнаний Текст В ЕХО. (вимкнено по дефолту, потрібен `feature_auto_schedule_gpu_messages_to_echo`)
6. опційно: завести нову operator_group групу для записів без джерела (наприклад тестові дані чи дані додані через імпорт папки). записати її id в config.toml:
```toml
# Відправляти розпізнані повідомлення в ЕХО автоматично
# feature_auto_schedule_gpu_messages_to_echo = true
# Група для аудіофайлів без джерела для автоматичної відправки в ЕХО
export_no_source_gpu_recs_to_group_id = "0198e7f8-53cd-7799-b16c-d461e5bacabe"
```
7. додати тестові дані (чи дочекатись реальних)
8. Зайти в ЕХО і перевірити що на вкладки аналіз та оперативний залітає нове перехоплення, із авторозпізнаним текстом і шляхом до файлу
