# АГЕНТИ

- ЕХО має поняття агентів: незалежних воркерів або API, що працюють із локальними моделями, читають дані ECHO та виконують вузькі задачі.
- Приклад агенту -- агент що прив'язує повідомлення до населених пунктів.
- У цій директорії лежить MVP для `analyst` агента, який формує користувацьку відповідь через `opencode` і локальний `vllm`.

## АРХІТЕКТУРА

- На `echo-gpu-spark` запущено `vllm` із моделлю `openai/gpt-oss-120b` або іншою сумісною моделлю.
- Агент працює в Incus-контейнері `echo-gpu-agent` і ходить до `vllm` по мережі через `vllm-host:8000`.
- `opencode/` містить конфіг для OpenCode, який підключається до `vllm`.
- `analyst/` містить невеликий Rust CLI, який запускає `opencode`, збирає стрім подій і повертає підсумковий Markdown.
- Для доступу до ECHO агент має ходити від окремого API-користувача з мінімально потрібними правами, наприклад роллю `ApiAgent`.

## СТРУКТУРА

- `opencode/`: конфіг OpenCode, helper-скрипт та skills
- `analyst/`: імплементація агенту що як відповідає на API-запити так і робить самостійну роботу
