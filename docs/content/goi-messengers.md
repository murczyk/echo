<span id="goi-messengers"></span>

В ЕХО є інтеграція з GOI, яка дозволяє підключати месенджери до інстансу GOI і використовувати їх для роботи з групами.

Для інтеграції з WhatsApp можна використовувати **Swapp** або **Swapp alt**. Вони також мають інші можливості, зокрема повторне надсилання повідомлень; деталі можна переглянути за посиланнями Swapp або Swapp alt у налаштуваннях GOI. Signal через Swapp не підтримується.

Також можна використовувати **Echo Messengers**. Посилання на нього доступне на сторінці `/goi-settings`, якщо для користувача налаштовано інстанс GOI.

{{ img(id="eim_1.png", alt="Сторінка Echo Messengers", class="textCenter") }}

Щоб підключити месенджер:

1. Додайте нову інтеграцію в Echo Messengers. Для цього використайте профіль Signal або WhatsApp, який плануєте застосовувати як бот для надсилання повідомлень з GOI.

{{ img(id="eim_2.png", alt="Додавання інтеграції", class="textCenter") }}

2. Натисніть `Підключитись` і відскануйте QR-код потрібним пристроєм.

{{ img(id="eim_3.png", alt="Підключення через QR-код", class="textCenter") }}

3. Перевірте статус інтеграції. Якщо статус не `Підключено`, зверніться по допомогу з налаштуванням інтеграції, бо це може означати проблему з підключенням.

4. Якщо інтеграція підключена, скопіюйте посилання на неї.

{{ img(id="eim_4.png", alt="Копіювання посилання інтеграції", class="textCenter") }}

5. Поверніться до ЕХО на сторінку `/goi-settings`, відкрийте посилання GOI, перейдіть у налаштування GOI і вставте посилання інтеграції в поле Signal або WhatsApp, залежно від типу підключення.

{{ img(id="eim_5.png", alt="Налаштування інтеграції в GOI", class="textCenter") }}
