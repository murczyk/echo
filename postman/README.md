# Використання колекції Postman
- Завантажити десктопний клієнт постмену
    - https://www.postman.com/downloads
- Зареєструвати акаунт
- Імпортувати колекцію `Echo.postman_collection.json`
    - Відкрити Postman
    - Перейти до вкладки "Collections"
    - Натиснути на "Import" і вибрати файл `postman/Echo.postman_collection.json` з репозиторію
- Запустити локальний сервер wdintel-rs `just dev-back`
- Перед використанням апі через постмен потрібно мати логін і пароль користувача
    - Якщо немає створити його: `./wdintel-rs --mode debug oneoff-register-user --login lys --password lys --role Admin --sigint-zone 1`
- Вказати актуальні змінні. 
  - Перейти до вкладки "Collections", вибрати колекцію `Echo`, натиснути на "Variables" і вказати:
      - base_url - Використовується в адресі запиту
      - login - логін користувача, використовується при авторизації
      - password - пароль користувача, використовується при авторизації
- Відправити запит на авторизацію `signin` для того щоб отримати Identity користувача 

# У разі зміни апі або додавання нових запитів
- Додати нові запити в колекцію
- Експортувати колекцію
    - Відкрити Postman
    - Перейти до вкладки "Collections"
    - Натиснути на три крапки біля назви колекції
    - Вибрати "More" -> "Export"
    - Вибрати формат `Collection v2.1 (recommended)`
    - Зберегти файл з назвою `Echo.postman_collection.json` в папку `postman` репозиторію
